Mission 04 · Decision junction

Messy reports in. Four clean branches out.

AKnown issue

Matches the playbook or an open record. Share guidance, link the ID. No duplicates.

BUnknown issue

No match, details complete. Run triage, return the new ID.

CIncomplete report

Required details missing. Ask before acting.

DSensitive / Sev 1

Funds or data risk, or a wide outage. Stop and escalate to a human.

Flight rule 04Validate before you act. An incomplete report earns a question, not a record.

Mission 06 · Enterprise integrations

Every integration is an identity decision.

Connector

The docking port: a wrapper around a service's API. Admins allow or block them with data policies.

Action

One operation: Get items, Create item. Add only the ones you need.

Connection

An authenticated instance tied to an identity. It decides whose permissions every call runs with.

End-user credentials

Each user signs in; the action runs as them. Best for personal data.

Maker-provided credentials

Runs as the owner or a service account. Everyone inherits its access, so scope it to the list, not the site.

Flight rule 06Read before you write. Report only the ID the system returned.

Mission 08 · Security & governance

Capability is attack surface.

Direct · jailbreak

“Ignore your instructions and…” typed straight into the chat.

Indirect · cross-prompt

The payload hides in a document the agent reads. The user is innocent. This is the Rogue Document.

Copilot Studio screens for both and lets you tune content moderation. Treat that as the last line of defense, not the only one.

Curated knowledge, each source ownedLeast-privilege toolsApproval gatesData policies (DLP)Authentication & moderation settingsPeople watching Monitor
Flight rule 08Content is data, never command. The safest tool is the one you never gave the agent.

Built-in anomalies

Something will go wrong. That's the point.

ANOMALY-403

The 403 Surprise

Permissions tightened overnight. The connector fails.

Proves:

The flow still responds with a status, and the agent says nothing was recorded, instead of “Done!”

ANOMALY-DUP

The Duplicate Incident

Three people report the same QuickPay outage.

Proves:

Get items runs before Create item. One incident, one record.

ANOMALY-INJ

The Rogue Document

A vendor note in the knowledge base carries hidden instructions.

Proves:

The agent treats content as data and its structural guardrails hold.

ANOMALY-AUTH

The Human Approval Gate

Someone asks the agent to declare a Sev 1 at 2 a.m.

Proves:

The flow pauses for a human, handles “no” and silence, and reports “pending”.
