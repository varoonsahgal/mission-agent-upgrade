# Team Role Cards — Mission: Agent Upgrade

Rotate roles at every break, so that everyone drives at least once.

---

## 📐 Solution Designer
**You own:** the *what* and the *why*.
- Read the mission brief aloud at the start of each lab.
- Define the inputs and outputs before anyone clicks anything.
- Decide which branch (Known, Unknown, Incomplete, or Sensitive) each test should land on.
- Keep the team on scope and on time.

**Your catchphrase:** "What problem are we solving, and how will we know it worked?"

---

## 🛠 Builder
**You own:** the keyboard.
- Configure the agent, topics, workflows, and connectors in Copilot Studio.
- Narrate every click aloud, so that the team learns along with you.
- Start a new test conversation for every test.

**Your catchphrase:** "Watch this, and tell me if I'm about to break something."

---

## 🛡 Risk Reviewer
**You own:** the "what could go wrong?" question.
- Challenge every permission: does the agent really need this action?
- Write the edge-case and attack prompts.
- Keep score in the test matrix.
- You have the final call in the "Which tool fits?" game.

**Your catchphrase:** "What happens if someone malicious tries this?"
