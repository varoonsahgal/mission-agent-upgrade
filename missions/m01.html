Briefing Discover

You already know how to build an agent in Microsoft 365 Copilot Agent Builder. You write instructions, point it at some knowledge, and in a few minutes you have a helpful assistant. So why would anyone need Copilot Studio?

Because answering is not the same as acting. The moment an agent has to create a record, follow business rules, wait for an approval, connect to a system of record, run on a schedule, or be governed across hundreds of users, you've outgrown the lightweight builder. This mission teaches you to spot that moment.

🛰️
Analogy

Agent Builder is the cockpit of a personal spacecraft. You can be airborne in minutes, and it's perfect for solo flights. Copilot Studio is Mission Control: the console where engineers wire up systems, set flight rules, add abort procedures, and monitor every launch.

Eight upgrade signals

If a scenario includes any of these, it's probably a Copilot Studio mission:

⚡ACT

It must change something

Create, update, or send. It writes to a system rather than just reading.

🔀DECIDE

It follows business rules

Branching, validation, and “if Sev 1, then…” logic.

🔌CONNECT

It talks to systems

Connectors, APIs, or data sources beyond Microsoft 365.

🧑‍⚖️APPROVE

A human must sign off

Approvals, escalation, and separation of duties.

⏰TRIGGER

It runs without being asked

Schedules, new emails, new records, and other events.

🌐PUBLISH

It reaches other audiences

Websites, members, or apps outside Microsoft 365 Copilot.

🛡️GOVERN

It needs guardrails

Environments, data policies, authentication, and ALM.

📈MEASURE

It must prove its value

Evaluation, analytics, and monitoring.

Copilot Studio today: what you'll see

The current Copilot Studio has a streamlined left rail: Home, Agents, Workflows, and Apps (Preview). When you select New agent you can choose:

  • Agent: the newer AI-first build experience, which consumes Copilot Credits.
  • Customer Assist Agent: purpose-built for customer conversations over chat and voice.
  • Agent (Standard): an agent with predefined rules and flows (topics, tools, triggers) that uses standard orchestration. Copilot Studio shows it as included with your Microsoft 365 Copilot license at no extra credit cost. This is the one we use in the labs.
Already have an Agent Builder agent? You don't have to start from scratch. Agent Builder agents can be copied into Copilot Studio, keeping their instructions and knowledge, and then upgraded with topics, tools, and flows. That's exactly the journey this workshop takes.
Rule of thumb Start in Agent Builder when you're talking to knowledge. Upgrade to Copilot Studio when you're acting on systems.
