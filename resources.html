// Cheat sheet

One page, every mission

Navigate Copilot Studio

  • Left rail: Home · Agents · Workflows · Apps (Preview)
  • Agent tabs: Overview · Knowledge · Tools · Agents · Topics · Activity · Evaluation · Monitor · Analytics · Channels
  • Settings (top right): security, generative AI, and more
  • Test toggles the test pane

Instructions that work

  • Role → scope → rules → tone → refusals
  • Use “never / always / only” for hard rules
  • Type / to reference tools and topics
  • No secrets: assume instructions can leak

Topic building blocks

  • Trigger → Question → Condition → Tool → Message
  • Entities validate answers (closed list, regex)
  • Variables: Topic.*, Global.*, System.*
  • Customize the On Error, Fallback, and Escalate topics

Workflow contract

  • Name and describe every input and output
  • Deterministic logic lives in the flow
  • Always respond to the agent, even on failure
  • Return Status + Reason + ID

Connector hygiene

  • Add only the actions you need
  • End-user credentials for user-scoped data
  • Service accounts scoped to the list, not the site
  • Look up before you create (no duplicates)

Human in the loop

  • Gate Sev 1, funds/data risk, and closures
  • Handle Approved · Rejected · Timed out
  • Truthful status: “pending” is not “done”
  • Log the approver and the time

Break it

  • Direct jailbreak vs. indirect (document) injection
  • Curate knowledge sources and give each one an owner
  • Data policies block risky connector mixes
  • Stack the six shields

Prove it

  • Fresh conversation for every test
  • Trace in Activity + flow run history
  • Test the failures (403, invalid input, out of scope)
  • Save the scenarios as an evaluation set

// Glossary

Mission vocabulary

Agent
An AI assistant built in Copilot Studio, combining instructions, knowledge, topics, and tools.
Agent Builder
The lightweight agent creator inside Microsoft 365 Copilot, for personal and team agents.
Agent flow
A workflow built in Copilot Studio (on the Power Automate engine) that an agent can call as a tool.
Connector
A packaged wrapper around a service's API, exposing actions and triggers.
Connection
An authenticated instance of a connector, tied to a specific identity.
Data policy (DLP)
An admin rule that controls which connectors can be used together in an environment.
Entity
A type that validates and normalizes user input, e.g., a closed list of service codes.
Environment
A container for agents, flows, and data, with its own security and policies (dev, test, prod).
Generative orchestration
The agent uses a model to choose which topics, tools, and knowledge to use, based on their descriptions.
Human in the loop
A design in which a person must approve or supply information before automation continues.
Knowledge source
Approved content the agent grounds its answers in.
Least privilege
Give the agent only the access and actions it needs, and nothing more.
Prompt injection
Malicious instructions placed in user input (direct) or content the agent reads (indirect).
Solution
A package for moving agents and flows between environments (ALM).
Topic
An authored conversation path with a trigger, nodes, variables, and conditions.
Tool
An action the agent can take: a connector action, flow, prompt, REST API, or MCP server.
Trigger
An event that starts an agent or flow: a message, schedule, new item, or email.
Verifiable result
An outcome the system confirms, such as a returned Issue ID, rather than the model's claim.
