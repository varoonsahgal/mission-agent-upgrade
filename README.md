# 🚀 Mission: Agent Upgrade

**From AI Assistants to Intelligent Business Solutions.** This is a 4-hour, hands-on Microsoft Copilot Studio workshop, delivered as two 2-hour sessions.

Learners take one fictional scenario, *Contoso Credit Union · Digital Services "Mission Control"*, and upgrade a basic troubleshooting assistant into a governed business solution. By the end it can:

- **Understand** issues using approved knowledge
- **Investigate** a SharePoint issue register
- **Decide** between guidance, follow-up questions, and escalation
- **Act** through agent flows (workflows)
- **Protect** the process with approval gates, least privilege, and prompt-injection defenses
- **Verify** results with evaluations, activity traces, and honest error handling

👉 **Live course site:** https://varoonsahgal.github.io/mission-agent-upgrade/
